# SportEventMap

SportEventMap hilft dabei, Lauf-, Triathlon- und Ultramarathon-Veranstaltungen
in Deutschland zu finden, zu vergleichen und für die eigene Saison zu planen.

Dieses Repository dient der Speicherung der Projektdateien und der
Nachverfolgung von Änderungen.

Die [Anleitung „Events manuell pflegen“](docs/MANUAL_EVENT_MAINTENANCE.md)
beschreibt den Admin-Pflegeweg, gezielte Quellenprüfungen und neue Editionen.
