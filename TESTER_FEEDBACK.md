# Sport Event Map - Tester Feedback

Use this sheet for closed beta interviews with runners, trail runners and triathletes.

## Core Understanding

1. Hast du verstanden, was die Plattform macht?
2. Hast du ein interessantes Event gefunden?
3. Würdest du die Seite erneut nutzen?
4. War die Suche hilfreich?
5. Hast du den Season Planner verstanden?
6. Was hat gefehlt?
7. Was war verwirrend?
8. Was hat dir besonders gefallen?

## Suggested Test Flow

1. Open the landing page.
2. Search for a race type, city or month.
3. Open an event from the map or list.
4. Save at least one event with the heart icon.
5. Open Season Planner.
6. Try changing priority and planned distance.
7. Use the feedback widget.

## Notes To Capture

- Did the tester understand the beta banner?
- Did the tester notice the map and filters?
- Did the tester use favorites naturally?
- Did the tester understand that favorites feed the Season Planner?
- Which data felt trustworthy or untrustworthy?
- Which event information was missing?
- Was anything hard to read on mobile?
